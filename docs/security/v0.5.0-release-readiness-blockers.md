## Enforced technical scope

- `IsolatedHostAdapter` now fails closed for **all untrusted subprocess execution**. Its historical Seatbelt process-execution implementation is dormant, not a certified sandbox. `StaticHost` still supports bounded allowlisted source reads. Host permission in another tool does not override this block.
- `ApprovalStore`: private host-owned parent directory, restrictive regular store/lock file modes, no-follow I/O, unpredictable exclusive temporary files, flock and fsync. Durable approval history cannot be cleared by the runtime API.
- `observe` and staging requests cannot be sent to `subprocess` through this adapter. Raw destination and path strings are no longer emitted into its host events.
- `render_report.py` cannot emit a positive legacy all-clear from unauthenticated, self-consistent JSON claims.
- Historical macOS runtime tests for executing target code are now marked unavailable while execution is disabled; **skip does not imply pass**.
