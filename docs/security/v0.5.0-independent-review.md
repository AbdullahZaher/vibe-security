All five were remediated with regression tests. The full suite at `c557b76` plus the reviewer-driven fixes is **227 tests, 226 passed, 0 failed, 1 skipped, exit 0**.

## 2. Needs-validation limitations (not exploited)

The reviewer flagged four plausible but unexploited risks:

- **C1:** `seal_evidence` review-directory check/use race (directory swapped between `is_dir()` check and iteration).
- **C2:** `trusted_root` treats an owner-`0555` parent of another user as immutable; that owner can `chmod` and replace a symlink.
- **C3:** `plan_guard` allowlisted Git observations (`git diff --no-ext-diff`, `git status`) can invoke repository-configured helpers (`textconv`, `fsmonitor`).
- **C4:** Coverage artifact containment is skipped when `--source-root` is omitted.

These remain documented limitations; none were exploited against reviewed fixtures.
