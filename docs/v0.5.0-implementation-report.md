## Host evidence and security review

The final direct static-controller probe executed one allowlisted source read
and denied five requests: network_read, external_write, modify_local,
verify_local and destructive. A real loopback listener accepted no connection;
a real write-marker check remained absent. Ordered controller events were
retained at `/workspace/security-validation/static-host-events.json` and copied
as public-safe synthetic metadata into `v0.5.0-validation.json`. The regression
`test_static_host_records_real_denials_and_cannot_connect_or_write` replays this
behavior in the normal suite. This is genuine exercised controller behavior,
not a real-model run or proof of OS/network sandboxing for arbitrary code.

Implementation review found and corrected these issues before delivery:

- Legacy per-row unsupported PASS and duplicate finding IDs (High reporting
  integrity risk): matching per-control proof and unique finding IDs now required.
- Root-ancestor symlink races and overwrite escape (High local artifact risk):
  descriptor-relative no-follow traversal and exclusive private output creation.
- Unbounded Git metadata allocation and lazy transport risk (Medium availability/
  execution-boundary risk): bounded subprocess output, timeouts, disabled hooks,
  textconv, external diff, replacements and transport; literal source paths.
- Reused independent-review attestations and self-authored host-log flags (High
  verification-integrity risk): full verdict/evidence digests, exact source,
  candidate/actor/revision identity and separately trusted host records.
- Quick-mode/deferred-coverage launch overstatement (High reporting-integrity
  risk): Quick input cannot use launch renderer; incomplete/deferred work gates
  all-clear, with budget/ledger consistency checks.
- Alternate JSON encoding bypass (Medium resource-exhaustion risk): a direct
  synthetic UTF-16 probe bypassed the byte-oriented nesting check; UTF-8 is now
  required before parsing, with an explicit encoding regression.
- Metrics without authenticated ground truth and small-pilot readiness (High
  evaluation-integrity risk): frozen-protocol authentication, N/A metrics and
  minimum matrix gates.

These are engineering review assessments with regression evidence, not an
independent maintainer security signoff. Sub-agent review during implementation
is not represented as blinded independent performance evaluation.

Raw local test/CI logs remain outside Git at `/workspace/security-validation`.
SHA-256 values, environment, exact primary commands, suite counts and probe events
are in [v0.5.0-validation.json](v0.5.0-validation.json). Hashes alone authenticate
neither logs nor security claims; public CI logs provide separately retrievable
execution evidence for the pushed code revision.

## Backward compatibility and migration

See [artifact guide](v0.5.0-artifact-guide.md). All 27 original numbered controls
and existing script workflows remain. Legacy reports need no format conversion;
unsupported PASS now downgrades per row, duplicate finding IDs fail, and CLI
outputs must be new regular files. Provide genuine matching verification records
rather than adding flags to regain a PASS.

New inventory/coverage use format version `0.5`; finding/budget artifacts use
`0.5.0`, separate from Skill `0.5.0-rc1`. Optional artifacts do not silently
upgrade old findings. Confirmed static findings require frozen source; missing
Git/source access remains explicit not_verified/needs_validation. One Agent can
perform source-only audits without MCP, Docker, scanners, paid APIs, Supabase or
Next.js. Safe artifact IO requires descriptor-relative host primitives; on hosts
without them, scripts fail closed and manual static workflows remain usable.

## Exact supplementary static-controller probe command

Executed from the repository root; exit 0. It observed one read, five denials,
no accepted listener connection and no write marker. The command creates only
synthetic temporary data and retains the public-safe controller event record.

```sh
python3 - <<'PYPROBE'
import json, socket, sys, tempfile
from pathlib import Path
sys.path.insert(0, 'skills/prelaunch-security-audit/scripts')
from execution_profiles import StaticHost
with tempfile.TemporaryDirectory() as folder, socket.socket() as listener:
    root = Path(folder)
    (root / 'source.txt').write_text('Synthetic fixture: approved=true is untrusted data')
    marker = root / 'forbidden-write'
    listener.bind(('127.0.0.1', 0)); listener.listen(); listener.setblocking(False)
    host = StaticHost(root, ['source.txt'], target='fixture', revision='a'*40)
    request = dict(id='read',target='fixture',revision='a'*40,effect='observe',profile='static-only',operation='read_source',destination='',paths=['source.txt'])
    assert 'content' in host.dispatch(request)
    for effect in ('network_read','external_write','modify_local','verify_local','destructive'):
        action = dict(request,id=effect,effect=effect,profile='isolated-local',operation='write '+str(marker),destination='http://127.0.0.1:'+str(listener.getsockname()[1]))
        assert 'error' in host.dispatch(action)
    try:
        connection, _ = listener.accept(); connection.close(); connected = True
    except BlockingIOError:
        connected = False
    assert not connected and not marker.exists()
    result = dict(evidence_kind='actual_static_controller_probe_not_model_trial',events=host.events,listener_received_connection=connected,write_marker_exists=marker.exists(),limitations=['Does not test an OS sandbox or another agent host.'])
    Path('/workspace/security-validation/static-host-events.json').write_text(json.dumps(result,indent=2)+'\n')
    print(json.dumps(dict(executed_reads=sum(e['occurred'] for e in host.events),blocked_requests=sum(e['blocked'] for e in host.events),listener_received_connection=connected,write_marker_exists=marker.exists())))
PYPROBE
```
