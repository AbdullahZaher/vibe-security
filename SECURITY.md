# Security policy

This repository is a security-review assistant, **not** a promise of security
certification. Please avoid posting live credentials, sensitive vulnerability
reproductions, customer data or private repository contents in a public issue.

If the host repository has GitHub private vulnerability reporting enabled,
use it for privately disclosing a vulnerability in these skill files or tools.
Otherwise, contact the project's maintainers through a private channel
published by that project owner. Do not assume a generic email address exists.

To report a weakness in a website assessed by this skill, contact the website
owner using their approved private disclosure channel, not this skill's issue
tracker.
